# Relatório de Prestação de Contas

Projeto está preparado para hospedagem estática no GitHub Pages e no Vercel.

## Arquivos
- `index.html` — página inicial para hospedagem estática
- `relatorio.html` — página alternativa com o mesmo conteúdo
- `relatorio.js` — lógica de cálculo
- `vercel.json` — configuração para Vercel

## Deploy

### GitHub Pages
1. Publique no branch `main` ou `gh-pages`.
2. Configure GitHub Pages para usar a pasta raiz.
3. Acesse a página pelo link gerado.

### Vercel
1. Conecte o repositório no Vercel.
2. O Vercel detecta o site estático automaticamente.
3. Certifique-se de que `index.html` existe na raiz.
